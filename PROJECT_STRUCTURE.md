# Структура cylinder-flexo1

Основной код перенесён в тематические каталоги: `interface/`, `models/`,
`mechanics/`, `mvi/`, `mkr/`, `flexoelectric/`, `physics/`,
`numerics/`, `results/`, `legacy/`, `tests/`, `config/`, `docs/`.

**В корне нет вспомогательных модулей.** Оставлены только Windows-скрипты
запуска, десять точек входа для обратной совместимости, файл
`cylinder_paths.py` для поиска модулей, `requirements.txt` и основные
конфигурационные файлы.

Работа системы:
1. `START_PROGRAM.bat` запускает `GUI_BOOTSTRAP.pyw`.
2. Тот вызывает `FINAL_GUI.py` в корне.
3. `cylinder_paths.activate()` подключает все тематические папки к импорту.
4. `FINAL_GUI.py` выполняет исходный `interface/FINAL_GUI.py`
   с настоящим значением `__file__`, необходимым для путей к ресурсам.
5. Старые имена импортов сохраняются, но исходные физические модули
   загружаются напрямую из тематических каталогов.

**Нельзя** вручную удалять исходные модули из папок `mechanics/mvi/mkr`.
Архив Биргера/J2 находится в `legacy/`, активная ветка его блокирует.

Выполнить `RUN_SELF_CHECK.cmd` после Pull для численных регрессий.
Факт корректного переноса сам по себе не означает численной верификации.
