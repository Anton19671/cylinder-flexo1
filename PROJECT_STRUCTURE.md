# cylinder-flexo1 — упругая цилиндрическая оболочка
Рабочая конфигурация — связанная вариационная механико-электрическая задача.
Материал только упругий (HOOKE / Green–Lagrange). Градиентные варианты:
G3D (полные ковариантные градиенты) и Gz (градиенты по толщине).
Модели: KL, FSDT/Timoshenko, Reddy, Carrera TE1–TE4.
Методы: МВИ фиксированного ранга 1–8 и МКР/разностная дискретизация.
Статика: нелинейный Newton. Динамика: Newmark и нелинейные итерации.

## Запуск
START_PROGRAM.cmd открывает GUI_BOOTSTRAP.pyw, затем FINAL_GUI.py.
Расчёт по CASE: RUN_FINAL_CASE.py. Серия фиксированных рангов: RUN_MVI_1_8.py.
Основной CASE требует solver_backend=VARIATIONAL_REFERENCE.
Никакой автоматической подмены метода или физической модели не предусмотрено.

## Каталоги
interface — новый GUI/CASE/маршрутизация.
mechanics — вариационная физика оболочки, директоры, натуральные условия.
flexoelectric — энтальпия и градиентная связь G3D/Gz.
physics — радиальные нагрузки и их проекции.
numerics — статический/динамический Newton, МВИ, MKР, SBP, диагностика.
config — G3D и Gz CASE для статических и динамических опытов.
tests — проверки оставшихся упругих модулей.
docs — математические записи активной модели.

## Статус
Гарантия на результат требует отдельного прохождения unit/regression,
проверки остатка, баланса работы, сеточной/временной сходимости,
сопоставления МВИ и независимой сильной МКР по алгоритму Крысько–Zhong.
