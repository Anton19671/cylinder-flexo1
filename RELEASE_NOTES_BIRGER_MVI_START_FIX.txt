Birger/MVI start fix, 2026-08-24

Scope:
- CUF TE kernels, Birger Phi(eps), material law, residuals and tangents are unchanged.
- The fix is limited to MVI profile-start/gauge handling used by the CUF MVI driver.

Changes:
1. cylinder_cuf_stage7d_general_internal_mvi.py
   - Fixed false RANK_DEGENERATE_PROFILE_TERM for valid small rank-1 profile seeds.
   - Degeneracy is now relative for rank>1; rank=1 is rejected only when the QR diagonal is truly zero.
   - If a frozen partner block becomes rank-degenerate during QR gauge handling, QR is skipped for that block and a diagnostic event mvi_partner_qr_skipped is emitted. The physical reduced solve is still responsible for accepting or rejecting the step.

2. cylinder_final_stage11a_dispatcher.py
   - Updated deterministic automatic CUF MVI X-profile seeds with phase-shifted independent shapes.
   - This avoids coarse-grid nodal zeros that made MVI-2 start with an effectively rank-deficient partner profile.
