CYLINDER SOLVER — GUI / RESULTS FIX
===================================

Scope
-----
Only GUI input/validation and postprocessing/output were changed.
Solver mechanics, tangents, MVI algorithms and Birger constitutive equations were not changed.

1. Copy / Paste in the whole GUI
--------------------------------
- Explicit keyboard support: Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+A.
- Windows alternatives: Ctrl+Insert, Shift+Insert, Shift+Delete.
- Right mouse button menu: Cut / Copy / Paste / Select all.
- Class-level bindings cover Entry, Text, editable Combobox and Spinbox controls,
  including controls created later in dialogs (e.g. individual boundary conditions).
- Manual typing remains fully available.
- Excel column/row paste is supported for list-valued entries.
- Birger table accepts two Excel columns (epsilon_i, sigma_i).
- Manual load-factor list accepts comma, semicolon, whitespace, tabs and newlines.
- Control-point table accepts tab-separated Excel rows.

2. K5 initial-slope check
-------------------------
- The user no longer enters a K5 initial-slope tolerance before Start.
- The K5 check is automatic from E0 and nu0.
- Internal initial-slope relative tolerance is fixed at 0.05.
- Legacy saved GUI/case values cannot turn this back into a required GUI field.
- K5/K6/V10 physical curve validation remains active.

3. Per-step graphs
------------------
For every accepted load step, postprocessing now saves practical 2-D maps for:
- displacements u, v, w;
- strain components (CUF E-components or KL strains) at bottom/mid/top integration layers;
- stress components (CUF S-components or KL stresses) at bottom/mid/top integration layers;
- epsilon_i and sigma_i at bottom/mid/top layers + max through thickness;
- thickness resultants (all stored components; tau-resolved when applicable);
- detF and max |J-1| diagnostics when available;
- deformed 3-D shell (existing per-step output retained).

4. Birger / plasticity 2-D zones
--------------------------------
Per accepted Birger step:
- min/max GB/G0 maps;
- bottom/mid/top GB/G0 maps;
- explicit 2-D Birger nonlinear zone anywhere through thickness;
- Birger nonlinear thickness fraction;
- if an explicit yield criterion (yield stress or yield strain) is supplied:
  explicit 2-D plastic zone anywhere through thickness,
  plastic thickness fraction,
  bottom/mid/top plastic-zone maps;
- x-z and theta-z cuts and through-thickness profiles retained.

Important: GB/G0 degradation is not automatically renamed "plasticity".  A true
plastic-zone mask is only produced when the user supplies an explicit yield criterion.

5. Load-deflection graph
------------------------
- Saved graph convention corrected to X = |w|max, Y = load factor.
- Mandatory origin (0,0) is included.
- NUMERIC/LOAD_DEFLECTION.csv is saved with the origin and all accepted steps.

6. Results GUI
--------------
- Added graph groups: "Деформации" and "Результанты".
- Stored resultants are exposed in the direct numeric field viewer.
