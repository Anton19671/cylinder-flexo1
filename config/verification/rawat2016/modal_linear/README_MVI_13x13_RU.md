# Rawat et al. (2016): MODAL MVI 1..8 и FDM на 13x13

63 самостоятельных CASE: 7 теорий (KL, FSDT, Reddy, CUF TE1..TE4) × [MVI 1..8 и FDM].

Все физические параметры идентичны опубликованному примеру: длина 2 м, радиус 1 м, толщина 0.05 м, E=210 ГПа, nu=0.3, плотность 7850 кг/м3, линейная кинематика, линейная упругость, без нагрузки, MACRO, оба торца CLAMPED (C-C), 9 точек Гаусса по толщине. Первые 6 собственных форм для каждого CASE.

- **MVI**: DENSE_REFERENCE + SBP21_PERIODIC_ODD, ранг 1..8, 13x13. Это собственный чередующийся вариационный модальный алгоритм Крысько–Кириченко Y/X, НЕ FDM.
- **FDM**: MATRIX_FREE_GMRES + SBP21_PERIODIC_ODD_CSR, 13x13 (тот же физический узловой шаг). Модальные частоты вычисляет новый проекционный LOBPCG; этот путь ещё требует численной проверки.
- Текущий MVI dense cap: не более 256 поверхностных узлов, 4096 полных DOF и 1600 X/Y направлений. На 13x13 для CUF TE4 MVI8 число направлений = 15·8·13 = 1560. MVI 17x17 **не допускается** существующей реализацией. Не подменять его FDM и не утверждать, что 17x17 MVI доступен.
- Сначала запустить CUF TE4 FDM 13x13, затем CUF TE4 MVI1 13x13. Если проходит — MVI2..8, затем другие теории. При ошибке сохранять журнал. Ни одна модальная серия пока не запускалась и не проверена численно.
- FDM 17x17,25x25,33x33 находится в родительском каталоге для отдельного анализа сеточной сходимости и литературного сопоставления.

Источник: Rawat, Matsagar, Nagpal (2016), *Finite Element Analysis of Thin Circular Cylindrical Shells*, DOI 10.16943/ptinsa/2016/48426; Table 2, C-C, L/R=2, h/R=1/20, m=1 и n=1...10. Эталонные частоты: 511,342,269,277,352,473,626,807,1012,1241 Гц. Сопоставлять по (m,n) и полям, не по простому индексу в отсортированном списке собственных векторов.

Отдельные `output_dir` — относительные пути; результаты и сравнение отсутствуют, так как расчёты не запускались.
