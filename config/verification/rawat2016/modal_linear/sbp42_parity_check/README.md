# Проверка пространственного расщепления на 13x13

Три CASE с теми же физическими параметрами Rawat (2016): CUF TE4, MACRO, LINEAR, E=210 ГПа, nu=0.3, плотность 7850 кг/м3, C-C, 6 собственных форм, n_gauss=9. Изменена **только** пространственная дискретизация по сравнению с исходной серией 13x13.

- MVI-1 / MVI-2: новый SBP42_FOURIER_ODD (плотный оператор на небольшой сетке; алгоритм Крысько–Кириченко Y/X, без замены).
- FDM: новый SBP42_FOURIER_ODD_CSR в matrix-free модальном решателе.

SBP42 — дифференцирование 4-го порядка внутри области и 2-го порядка у границ, удовлетворяющее дискретной формуле Грина. Оно связывает чётные/нечётные осевые узлы, которые были разъединены SBP21 после применения Dirichlet BC.

Эти файлы предназначены для воспроизводимой проверки гипотезы, **не** означают, что частоты уже проверены. Сравнивать формы по полям и (m,n), затем сравнивать частоты по сети 13/17/25. Никакие расчётные серии автоматически не запущены. Сохранены исходные старые JSON и их результаты.
