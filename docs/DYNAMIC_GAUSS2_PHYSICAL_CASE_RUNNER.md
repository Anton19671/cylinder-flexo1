# Запуск физического CASE: экспериментальный МВИ + IRK4

Добавлен отдельный модуль `interface/cylinder_gauss2_case.py`.
Он использует **тот же физический CASE**, который проходит
`prepare_reference_case` для основного МВИ + Ньюмарк: геометрию,
материал, кинематику оболочки, градиентную энергию, флексоэлектрическое
сопряжение, пространственную нагрузку, временной закон, плотность,
начальные значения и граничные условия.

Внутренние времена двух стадий Гаусса проверяются отдельно.
Нагрузка на каждой стадии равна исходной пространственной нагрузке,
умноженной на значение физического временного закона при времени
соответствующей стадии.

Пример запуска из уже существующего JSON:

```python
from cylinder_paths import activate
activate()
from cylinder_gauss2_case import run_gauss2_mvi_case
result=run_gauss2_mvi_case(
    "config/CASE_REFERENCE_CUF_G3D_MVI_DYNAMIC.json",
    output_dir="OUTPUT_EXPERIMENTAL_GAUSS2")
```

**Никакого автоматического переключения:** обычные
`run_final_case` и GUI продолжают запускать Ньюмарка. Для IRK4
требуется отдельный явно указанный каталог, совпадение с каталогом
Ньюмарка запрещено. Физический паспорт передаётся в драйвер истории.

Ограничения пока сохраняются: экспериментальная плотная реализация
для малых сеток, только неподвижные существенные механические опоры,
фиксированный ранг без повышения и усечения, возможен отказ шага,
если коллокационное конечное поле не представимо при данном ранге.
Не объявлять глобальный порядок 4 после ограничения ранга без
независимой проверки. Численная проверка семи теорий ещё не завершена.

Тесты: `tests/test_gauss2_case.py`. Они проверяют подготовку
физики, нагрузку, запрет изменения основного каталога и правильную
передачу исходного CASE без полного оболочечного расчёта.
