GRAPH AXES, UNITS, EXCEL HEADERS, DETACHED WINDOWS
==================================================

Scope
-----
This update changes only GUI and output/postprocessing code.  Shell equations,
tangents, Newton, MVI, Birger and boundary-condition mechanics are unchanged.

Graphs
------
- Load-deflection uses X=|w|max with length units and Y=the actual dimensional
  load q or p_line.  Lambda is not substituted for a known physical load.
- Every surface map uses physical x and circumferential arc coordinate s.
- 3D shell plots label x, Y and Z and include a labelled w colour scale.
- Stress, strain, displacement, resultant, plasticity and convergence plots use
  explicit units; dimensionless quantities use [-].

Excel and CSV
-------------
- Column headers include quantity names and units.
- Load_Deflection contains step, lambda, actual load, deflection and status.
- The embedded scatter chart uses deflection on X and actual load on Y, with
  both axis units shown.
- Long-form surface, thickness, CUF coefficient, standard-z and resultant
  tables include coordinate and value units.

GUI
---
- Load-deflection, 3D shell, field/plasticity and convergence plots have an
  "Open graph in separate window" command.
- Saved result graphs can be opened separately by button or double click.
- Detached graph windows are resizable and include zoom, pan, home/back and
  image-save controls.
