# Единый формат Excel для Cylinder-Flexo1

Требование распространяется на **все книги Excel**, создаваемые решателем, а не только на MODAL. Реализовано через единый модуль `numerics/cylinder_excel_tables.py`.

- Каждый параметр занимает **отдельный столбец**, не соединяется с другими числами в одной ячейке.
- В первой строке каждого листа написаны **русское название величины, математическое обозначение и единица СИ** (если есть); закреплена строка заголовка и доступен фильтр.
- У каждого столбца есть всплывающий комментарий с физическим смыслом, кодом и единицей.
- Во **всех книгах** есть лист `ОБОЗНАЧЕНИЯ`: имя листа, название столбца, исходный код, символ, единица СИ, пояснение. Ссылки ведут на исходные листы.
- Единый чёрно-белый/серый стиль; значения сохраняют исходную точность, не пересчитываются при экспорте.
- Для специфического поля без известного определения единица не выдумывается: явно требуется уточнение по CASE.
- Этот стандарт применяется к `00_DYNAMIC_INDEX.xlsx`, `01_SIGNALS.xlsx`, `02_FOURIER_FFT_PSD.xlsx`, `03_PHASE_ATTRACTORS.xlsx`, `04_POINCARE.xlsx`, `05_LYAPUNOV.xlsx`, `06_BIFURCATION.xlsx` и `00_MODAL_RESULTS.xlsx`.

## MODAL

Листы `FREQUENCIES`, `PARAMETERS`, `MODE_FIELDS`, опционально `ELECTRIC_MODES`, и `ОБОЗНАЧЕНИЯ`. В `MODE_FIELDS` каждая запись соответствует одной форме колебаний и одному узлу; столбцы с координатами x, s и theta отделены от всех компонент. Для KL выводятся u,v,w; FSDT/Reddy — u,v,w и оба угла; CUF TE1..TE4 — все коэффициенты u_k, v_k, w_k. В электрической ветке каждый phi_k имеет отдельный столбец.

Файлы `.npz` остаются полными источниками данных; Excel — удобное подписанное табличное представление. Модальный анализ пока является малосеточной reference-реализацией, не подтверждён численным сравнением с эталоном. Расчёты здесь не выполнялись.
