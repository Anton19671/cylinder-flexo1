# Проверка независимых временных методов: МВИ + Ньюмарк / МВИ + IRK4

**Статус:** независимый сравнитель архивированных траекторий добавлен.
Это НЕ доказательство точности по времени, НЕ утверждение о полном
завершении оболочечной модели и НЕ автоматический запуск IRK4 из GUI.

Новые файлы:

- `numerics/cylinder_dynamic_case_passport.py` — формирует SHA-256
  объявленной физической постановки. Исключаются только настройки
  пространственного и временного алгоритма. Материал, геометрия,
  заданные нагрузки, временной закон, краевые условия, сетка,
  плотность и временной интервал обязаны совпадать.
- `numerics/cylinder_gauss2_mvi_history.py` — опциональный параметр
  `physical_case=case`, при котором перед запуском сверяются ранг,
  временная сетка и плотность, а в JSON записывается отпечаток.
- `interface/cylinder_reference_case.py` — сохраняет тот же
  отпечаток для действительного динамического запуска MVI + Ньюмарк.
- `numerics/cylinder_newmark_gauss2_comparison.py` — сопоставляет
  только две полностью завершённые сохранённые истории одинаковой
  объявленной физической задачи. Проверяет начальные поля и время
  каждого шага, сравнивает механические перемещения, скорости и
  электрические коэффициенты без их искусственного восстановления.
  Истории без физического отпечатка отклоняет.

Пример сравнения уже рассчитанных архивов:

```python
from cylinder_newmark_gauss2_comparison import compare_newmark_gauss2_mvi
comparison=compare_newmark_gauss2_mvi(
    "results/NEWMARK", "results/GAUSS2")
```

Запуск гауссова метода должен получить `physical_case=case`, где
`case` — **тот же подготовленный физический CASE**, что и у Ньюмарка;
и соответствующие его `loads_at(t)` и объект физической задачи.
Совпадение JSON отпечатков подтверждает только объявленную физику:
сравнитель не может математически доказать, что произвольный
переданный Python callback исполняет именно эту нагрузку.

Для старых файлов без отпечатка сравнение намеренно не производится:
их можно использовать для других целей, но нельзя задним числом
заявлять об идентичности исходных задач.

**Не закончено:** автоматическое построение физического маршрута
IRK4 из CASE, поддержка движущихся опор, массовая проверка семи
кинематик G3D/Gz по МВИ 1–8 и исследования сходимости по шагу времени.
Отдельные тесты хранятся в `tests/test_dynamic_case_passport.py`
и `tests/test_newmark_gauss2_comparison.py`. Проверки этого этапа
добавлены в репозиторий; не утверждать об их прохождении до
выполнения CI/локального запуска.
