# Исправление нагрузки на физическую поверхность KL — 15.11.2026

## Подтверждённый дефект

В кампаниях native_flexo_loaded_models и native_gradient_fdm_mvi_campaign
наружное номинальное радиальное давление для KL + Green–Lagrange
передавалось только как обобщённая сила к w0 с множителем H(z).
Однако текущая кинематика cylinder_kl_g3d_weak использует
u(z) = u0 + z (n - e_r), поэтому
w(z) = w0 + z (n_r - 1).
В прежней нагрузке отсутствовала вариация поворота нормали.

## Исправленная постановка

Параметр CASE kl_radial_face_traction содержит face и traction_pa.
Положительная traction_pa направлена по исходному наружному радиальному
базисному вектору. Положительному давлению внутрь соответствует отрицательная
traction_pa. Функционал внешней работы на единицу исходной срединной площади:

W_ext = traction_pa * (1 + z/R) * [w0 + z*(n_r - 1)].

Это номинальная радиальная нагрузка на исходной поверхности.
Следящее давление по нормали деформированной поверхности не вводится.
Изменяющийся во времени load_time_law вместе с этой опцией пока отвергается.

Локальная первая вариация включает коэффициенты при delta(q),
delta(q_x), delta(q_s). Она вычисляется из
delta(n) = (I - n*n^T) delta(A cross B) / |A cross B|.
Внешняя работа и её коэффициенты вычитаются из внутренней энергии
и её первой вариации.

Физическая формула общая. MVI и FDM подставляют собственные пространственные
производные и независимо собирают уравнения. Ни один метод не вызывает
численный решатель другого метода.

Старая обобщённая нагрузка mechanical_load по-прежнему имеет собственный
смысл. Кампании KL теперь задают её нулевой и используют физическую нагрузку
через новую опцию, чтобы не приложить радиальную силу дважды.

Восстановление наружного и внутреннего радиального перемещения KL в
сравнительной кампании также учитывает z*(n_r-1).

## Выполненная проверка

GitHub Actions: https://github.com/Anton19671/cylinder-flexo1/actions/runs/43743565425

126 тестов прошли. Проверены:
- точный результат для однородно наклонённой нормали;
- центральная проверка производной работы на внутренней, средней и наружной поверхностях;
- линейная и фон-кармановская кинематика;
- производная дискретной потенциальной энергии независимой MVI-сборки;
- коэффициенты независимой FDM-сборки;
- компиляция одинаковой физической нагрузки обоими методами в статике и динамике;
- паспорт и ранговые входные данные кампании.

Это локальная и сборочная верификация нагрузки, а не новая физическая
сходимость всей оболочки. Прежние результаты KL с нагрузкой только к w0
нельзя подписывать как результаты исправленного наружного давления.
Требуется повторить физические расчёты на новой версии.
