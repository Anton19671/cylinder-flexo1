Birger outer omega fix
======================

Changed:
- cylinder_te1_stage5a_birger.py now keeps Birger relaxation omega fixed at
  the value specified in the case/GUI for the whole load step.
- Removed the internal adaptive omega update that could silently change the
  submitted material iteration after a few Birger outer iterations.
- final_birger_curve.py now permits comparison operators in formula mode, so
  the documented expression where(eps<=epsT, ..., ...) is accepted by the
  same safe formula parser that already allowed where().
- FINAL_GUI.py adds a Birger curve "Open graph" button that opens the current
  Phi(epsilon_i) preview in a separate matplotlib window with toolbar.

Why:
- The GUI exposes omega as a user-controlled Birger outer relaxation
  coefficient.  The solver must not replace it during the run.
- With a softer Birger curve the adaptive branch could make the material outer
  loop look unstable/heavy even when the frozen-GB MVI solve itself converged.

Unchanged:
- CUF TE1/TE2/TE3/TE4 equations.
- MVI X/Y kernel.
- Birger secant formula GB = Phi(epsilon_i)/(3 epsilon_i).
- Green-Lagrange/linear kinematics.
- Boundary conditions and load builder.

Checked:
- python py_compile for the edited Birger and CUF MVI files.

- V3C_SELF_CHECK.py active Birger outer: PASS.
