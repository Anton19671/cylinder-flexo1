# Связанная главная часть системы Крысько–Zhong: KL / Тимошенко / Редди / CUF TE1–TE4

**Статус:** `COUPLED_SYMBOL_DIAGNOSTIC_NOT_STRONG_ORDER_CERTIFICATE`. Это не самостоятельный численный решатель сильной МКР и не доказательство корректности граничной задачи.

## Математическое основание

Полная геометрически нелинейная электрическая энтальпия и её локальная первая вариация **не дублируются**. Используются существующие ядра `cylinder_kl_g3d_weak.py`, `cylinder_director_g3d.py`, `cuf_g3d_weak.py`, общее материальное ядро `flexo_gradient_g3d.py`. При изменении `gradient_model` с G3D на GZ меняется материал, а не вид численного оператора.

Для обобщённых переменных \(U=(q_1,\ldots,q_m,\psi_0,\ldots,\psi_P)\) и независимых поверхностных мультииндексов \(\alpha=(a,b)\):

\[
A_{I\alpha}=\frac{\partial \mathcal L}{\partial U_{I,\alpha}},\qquad
H_{I\alpha,J\beta}=\frac{\partial A_{I\alpha}}{\partial U_{J,\beta}}.
\]

*Механика:* KL / FSDT / Reddy имеют десять независимых джетов до третьего порядка; CUF TE1–TE4 — шесть до второго. Смешанные \(q_{,xs}\), \(q_{,xxs}\), \(q_{,xss}\) учитываются по одному разу. *Электричество:* каждая активная мода потенциала имеет три джета \((\psi,\psi_{,x},\psi_{,s})\); электрической инерции нет.

При замороженных в выбранном состоянии локальных коэффициентах и физическом окружном координатном расстоянии \(s=R\theta\) полный символ линейного пространственного оператора:

\[
\mathsf P_{IJ}(k_x,k_s)=
\sum_{\alpha,\beta}(-ik_x)^{\alpha_x}(-ik_s)^{\alpha_s}
H_{I\alpha,J\beta}
(ik_x)^{\beta_x}(ik_s)^{\beta_s}.
\]

Функция `homogeneous_degrees` даёт разложение \(\mathsf P(tk)=\sum_{d=0}^6 t^d\mathsf P_d(k)\). Смешанные механико-электрические блоки сохраняются вместе с комплексными нечётными степенями, а не принудительно исключаются. Проверяется взаимность \(H=H^T\) отдельно для механического, электрического и поперечного блоков. Некорректная взаимность **отвергается**, а не скрывается симметризацией.

Производные локальных коэффициентов по джетам вычисляются центральными дифференциальными приращениями **уже существующей первой вариации энтальпии**, а не дифференцированием дискретного вариационного МКР. У произвольного деформированного состояния должны быть явно заданы масштабные значения разных джетов (их размерности различаются). Это численная диагностика касательной, не аналитически подтверждённая точная касательная.

## Что нельзя выводить только из символа

1. Максимальный порядок записанного джета **не означает**, что каждая механическая переменная имеет уравнение шестого (или четвёртого) порядка. Существенны взаимные блоки, возможное вырождение старшей части и характер направления \((k_x,k_s)\).
2. Таблица максимальных степеней **не есть** веса Дуглиса–Ниренберга, проверка эллиптичности, ранговые условия на характеристических направлениях либо самостоятельное доказательство числа граничных условий.
3. Определение корректного набора торцевых условий требует отдельной проверки полной связанной матричной главной части, включая гибридные порядки и электрические ограничения / калибровку потенциала.
4. Ни один из семи вариантов **не переключается** автоматически на сильную МКР. Сохраняется основной вариационный путь и фиксированные ранги МВИ 1–8.

## Проверки и ограничения

Синтетические тесты проверяют (i) Hermitian-структуру механико-электрической касательной, (ii) знак/порядок \(k_x^2,k_x^4\) и смешанный \(k_x^2k_s^2\), (iii) нечётный мнимый перекрёстный блок, (iv) отсутствие удвоения \(q_{,xs}\), (v) отказ от невзаимной касательной и необоснованных масштабов, (vi) раздельность полиномов по направлениям. Полную диагностику **реальных локальных** ядер для 7 теорий × G3D/GZ можно запустить отдельно по разрешению пользователя: `CYLINDER_LOCAL_SYMBOL_AUDIT=1`. Она не заменяет физические сеточные испытания, и её результаты **не заявлены выполненными**.

**Ещё требуется:** получение весов связанной смешанно-порядковой системы, физически полной матрицы торцевых условий (включая электрические условия на лицах), независимого сильного разностного решения и верификации по независимым задачам. Версия `NOT_NUMERICALLY_CERTIFIED` сохраняется.
