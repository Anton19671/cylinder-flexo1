## Установлено в решателе cylinder

1. Используется представление поля в виде суммы произведений одномерных координатных функций с фиксированным рангом.
2. Для нулевого начального поля ненулевые X-множители и нулевые Y-множители позволяют начинать с **Y-полушага**.
3. Второй полушаг — **X**; партнёрские функции в каждом полушаге фиксированы.
4. Решается система линейных уравнений для поправок активных одномерных функций, собранная проекцией исходной вариационной постановки; `np.linalg.solve` выполняет решение редуцированной системы. Полного двумерного шага Ньютона и спектрального `eigh` для полушага нет.
5. Варианты `PLATE_STYLE_ONE_CORRECTION` и `STRICT_HALFSTEP` различаются числом поправок в полушаге; нормировка QR и балансировка пар не меняют физическое поле.
6. Этот алгоритм в `cylinder` решает **пространственное равновесие**. В данном репозитории не обнаружена готовая реализация модального спектра по Крысько–Кириченко. Нельзя объявлять её перенесённой в MODAL автоматически.

## Установлено в cylinder-flexo1

- `numerics/cylinder_modal_mvi.py`: `_SeparatedModalProblem.halfstep` строит редуцированные `K`, `M` и вызывает `scipy.linalg.eigh`. Это проекционное решение собственной задачи, названное в коде `Rayleigh--Ritz`, а не коррекция одно-мерных вариационных уравнений по образцу `cylinder`.
- Последовательность сейчас X→Y, в отличие от Y→X в `cylinder`. Просто поменять порядок без изменения начальных функций нельзя: текущий комментарий предупреждает о вырождении пространства Y-вариаций при недопустимых исходных X.
- Частота затем повторно определяется отношением форм работы жёсткости и массы; это не проверка вариационных X/Y-уравнений.
- В `solve_modal_mvi` изменение формы считается формулой `sqrt(2 - 2 * min(1, overlap))`, которая верна лишь для **обеих** массово нормированных форм. Текущая форма нормируется по массе лишь после завершения циклов; следовательно, этот критерий может ошибочно принять изменение формы за ноль.
- Для кратных частот необходимы явное сохранение независимых массово-ортогональных форм и проверка всей группы; независимая последовательная обработка с дефляцией сама по себе не является проверкой кратного спектра.
- В конце строка `mvi_modal_algorithm` содержит `Rayleigh_Ritz`: алгоритм не следует переименовывать, пока не заменена действительная математическая процедура.

## Что необходимо реализовать перед заявлением «модальный МВИ Крысько–Кириченко»

1. Сформулировать собственные колебания на исходных вариационных формах жёсткости и согласованной инерции цилиндра: при `lambda=omega**2` обеспечить стационарность по разделённым X/Y-функциям с массовой нормировкой, не вводя фиктивную инерцию электрических DOF.
2. Дать точные редуцированные одномерные уравнения для X-полушага при фиксированном Y и Y-полушага при фиксированном X и математически описать обновление параметра `lambda`. **Не заменять** их вызовами `eigh` в каждом полушаге либо произвольной обратной итерацией без согласованного вывода.
3. Использовать обоснованные начальные функции, сохраняющие нужные опорные условия и ненулевое пространство первого полушага; согласовать последовательность **Y→X**, принятую для нулевого поля в `cylinder`, с модальной постановкой.
4. После каждого полного цикла корректно нормировать поле по массе и сравнивать формы с учётом знака; не использовать формулу через перекрытие для ненормированных полей.
5. Для нескольких собственных форм обеспечить массовую ортогональность, контроль независимости, обработку кратных частот и однозначную привязку номера формы к найденной частоте.
6. Сохранять отдельный журнал MODAL с событиями каждой одномерной вариационной задачи, цикла, частоты, амплитуды и затраченного времени. При остановке сохранять отдельные промежуточные данные как **неподтверждённые**, не как `MODAL_COMPLETED`.
7. Сравнивать **на одинаковом CASE и сетке** с независимой MODAL/MKR (в этой реализации FDM) веткой: частоты в Гц, относительные отклонения в %, массовая ортогональность, формы и их согласованность с учётом кратности, зависимость от ранга МВИ-1..8.
8. До численной проверки не присваивать статус «верифицирован» и не утверждать достижение точности метода.
