# Граничные условия: пространственная сборка

`numerics/cylinder_boundary_spatial.py` соединяет единый объёмный функционал
с механической работой на торцах, пружинами, высшими следами, электродами
и поверхностным зарядом. Для статики добавлен отдельный проверочный маршрут
CASE, описанный ниже. Обычный производственный маршрут MICRO и динамики
по-прежнему заблокирован.

Поддерживаются KL, FSDT, Reddy и CUF TE1–TE4. Выключенная электрическая
часть полностью исключается из вектора неизвестных. Все величины задаются
в СИ; порядок полей — `(компонента, x, s)`, электрические коэффициенты
следуют за механическими. Это отличается от `(компонента, s, x)` старых
производственных маршрутов, поэтому прямой передачи массивов между ними нет.

Условия задаются линейными строками `C u = d(t)`. Аффинное представление
`u = u0 + B z` обеспечивает `C u0 = d(t)` и `C B = 0`. Пространственные
уравнения получаются как `B.T R = 0`, касательная — `B.T K B`.
Полный остаток сохраняет реакции закреплений и электродов, поэтому его
нельзя требовать равным нулю на закреплённых степенях свободы.

МКР (`method="FDM"`) использует все узловые направления. Для полушага МВИ
передаётся матрица направлений замороженного семейства X или Y, построенная
через `separated_profile_directions(X, Y, "X"/"Y")`; ранги — 1–8.
Ограничения накладываются внутри этого пространства. Если заданные следы
недостижимы, сборка возвращает ошибку, без перехода к полносеточному решению.
Для неоднородных условий нужно отдельно хранить аффинное поднятие и
представлять МВИ допустимую добавку. Малый остаток одного полушага ещё
не подтверждает полное равновесие.

Для изолированной электрической системы проверяется суммарный объёмный
и поверхностный свободный заряд, затем добавляется калибровка среднего
потенциала. При наличии электрода с заданным потенциалом калибровка
не добавляется; электрод может поставлять заряд. Проверка баланса использует
относительную точность и не пропускает дисбаланс из-за малых единиц Кл.

В DYNAMIC на каждом времени заново вычисляются заданные перемещения,
потенциалы и нагрузки. Вектор ускорений и плотность можно передать в ту же
сборку: механическая инерция берётся из соответствующего CUF/director
функционала, электрическая масса не добавляется. Нелинейная инерция KL
остаётся явно неподдерживаемой. Это ещё не полный цикл Ньюмарка.

Проверки: `tests/test_boundary_spatial.py`, а также существующие тесты
вариационного функционала, граничной работы и CASE. Они проверяют допустимые
следы, энергетические производные, проекцию касательной, реакции, балансы
заряда, временные данные и применение выбора в GUI без ручной синхронизации
JSON. Эти проверки не являются исследованием сходимости оболочечного решения.

Следующий этап — адаптеры порядка полей и масштабов для производственных
циклов МВИ/МКР, затем полный шаг Ньюмарка с проверкой допустимого остатка,
реакций и кинематической совместимости начальных/граничных данных. До этого
снятие блокировок в dispatcher/capability registry было бы преждевременным.

Плотная сборка ограничена 4096 неизвестными/строками и предназначена для
малых проверочных задач. Она не заменяет разреженную производственную сборку.

## Запускаемый статический МКР

`numerics/cylinder_variational_fdm.py` решает связанные нелинейные узловые
уравнения методом Ньютона. `solver_backend="VARIATIONAL_REFERENCE"` явно
выбирает этот маршрут в `run_final_case` и `validate_final_case`. Пример:

```bash
python RUN_FINAL_CASE.py config/CASE_REFERENCE_CUF_G3D_STATIC.json
```

Числа в примере предназначены для проверки программы, а не для воспроизведения
конкретного материала или эксперимента. Результаты сохраняются в отдельную
папку, заданную `output_dir`. Повторный запуск требует новой пустой папки.

Маршрут принимает STATIC, FDM, GREEN_LAGRANGE, HOOKE и СИ. Доступны KL,
FSDT, Reddy, CUF TE1–TE4; MACRO либо MICRO G3D с флексоэффектом ВКЛ/ВЫКЛ.
В CASE нужен явный вариационный паспорт ГУ. Электрические ГУ при флексо ВЫКЛ
необходимо переключить на INSULATED. Текущий GUI этот специальный формат
не редактирует и сообщает об этом при попытке загрузки; запуск — через CASE.

Нагрузка: равномерное мёртвое радиальное давление на срединной поверхности
(`UNIFORM_RADIAL_FACE`, `MIDDLE`, `DEAD_REFERENCE`, положительное q — наружу)
либо явные обобщённые нагрузки `reference_loads.mechanical` и
`reference_loads.free_charge`. Обобщённые нагрузки сопряжены коэффициентам
полей и не являются произвольным давлением на внешнюю поверхность. Вектор
по компонентам разворачивается равномерно по сетке; также принимаются полные
массивы `(компонента, x, s)`. `load_factors` задаёт статическую серию:
масштабируются эти нагрузки, но не заданные перемещения/потенциалы в ГУ.
Нагрузки на внешнюю/внутреннюю поверхность и следящие силы пока отклоняются.

Касательная вычисляется центральными разностями от той же первой вариации.
Связанная неопределённая система решается напрямую; поиск шага уменьшает
остаток, а не энтальпию электрической седловой системы. Вырожденная касательная
вызывает отказ без регуляризации. Отдельно контролируются условия закреплений,
электроды и полный допустимый остаток; реакции сохраняются отдельно.

Поля нормируются: поступательные/CUF коэффициенты на h, повороты на 1 рад,
потенциал на `potential_scale_v`; энергия — на `E*h*area`. Абсолютный допуск
относится к производной этой безразмерной энергии, относительный — к начальному
допустимому остатку данного шага. Масштабы и оба остатка записываются в отчёт.

Выход: `FINAL_RUN_SUMMARY.json`, исходный `REFERENCE_CASE.json`,
`REFERENCE_STEP_0001.npz` и `REFERENCE_NEWTON_0001.json` для принятого шага.
NPZ содержит механические коэффициенты, электрические коэффициенты при ВКЛ,
остаток и обобщённые реакции `constraint_reaction` (нормальная к допустимым
вариациям часть внутреннего остатка минус заданные нагрузки). В отчёте есть
максимальный срединный прогиб `w_middle_abs_max_m`. Неуспешная итерация
записывается как `REFERENCE_FAILED_ITERATE.npz` и не считается принятым шагом.
Формат этих файлов отличается от старых STEP-файлов; старый постпроцессор
нельзя применять без адаптера.

Ограничения: до 256 поверхностных узлов; по умолчанию до 256 свободных степеней
свободы (жёсткий максимум 512). Минимальная квадратура по толщине: 3 точки
для KL/FSDT/TE1, 5 для TE2, 7 для Reddy/TE3, 9 для TE4. Это предотвращает
явное недоинтегрирование и не заменяет проверку квадратурной/сеточной
сходимости. Разреженная сборка, полные циклы МВИ и Ньюмарк остаются следующими
этапами. Проверки нового решателя — `tests/test_variational_fdm.py`, включая
реальный связанный расчёт CUF TE1, сохранение полей, седловую электрическую
систему и отказ при вырожденной касательной.
