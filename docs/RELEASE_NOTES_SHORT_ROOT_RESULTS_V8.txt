CYLINDER SOLVER v8 — SHORT ROOT RESULTS
=======================================

1. Сохранена правка общей фиксированной нагрузки для серии МВИ 1–8 из v7.
2. В Windows новый каталог результатов по умолчанию: C:\CYL_RESULTS.
3. Папки запусков создаются сразу в корне результатов:
   C:\CYL_RESULTS\RUN_001__...
4. Удалён промежуточный длинный уровень CASE__... между корнем и RUN_....
5. Общий индекс всех запусков сокращён до C:\CYL_RESULTS\RUNS_INDEX.csv.
6. Нумерация RUN_001, RUN_002, ... теперь общая для всего корня результатов.
7. Старые результаты не перемещаются и не удаляются; новый путь применяется к новым запускам.
8. Численное ядро, постановка и параметры квадратуры этой правкой не изменялись.
