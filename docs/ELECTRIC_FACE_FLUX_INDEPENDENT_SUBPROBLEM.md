# Независимый электрический потоковый эталон (§40.1)

Статус: `DIELECTRIC_SUBPROBLEM_ONLY`. Это **не** полная независимая сильная
механико-электрическая МКР и **не** проверка полной флексоэлектрической связи.

Для электрического TE0 (φ не зависит от толщины), нулевых механических
деформаций и постоянной диэлектрической проницаемости κ используем:

- \(I_x=\int_{-h/2}^{h/2}(1+z/R)\,dz=h\).
- \(I_s=\int_{-h/2}^{h/2}(1+z/R)^{-1}\,dz
  =R\ln[(R+h/2)/(R-h/2)]\).
- Гранные интегралы потока: \(F^x_{i+1/2,j}=-\kappa I_x\Delta_x\phi/\Delta x\),
  \(F^s_{i,j+1/2}=-\kappa I_s\Delta_s\phi/\Delta s\).

Энтальпия имеет отрицательную диэлектрическую часть, и сумма невязок для
изолированного цилиндра равна нулю. По окружности гранный, а не центральный
нодальный оператор не имеет паразитной нулевой моды при чётном числе узлов.

Файлы: `numerics/cylinder_electric_face_flux.py`,
`tests/test_electric_face_flux.py`.

Проверки: численная производная энергии, калибровка потенциала,
зарядовый баланс, шахматная гармоника для чётных \(n_s\); дополнительный
тест сравнивает полный связанный вариационный `electrical_residual`
для всех семи кинематик и G3D/Gz **только** в пределе
\(q=0,\;\partial_x\phi=\partial_z\phi=0\).

Самостоятельные четыре теста оператора выполнены локально на Python/NumPy.
Интегрированный тест семи теорий требует доступного полного репозитория
и пока **не выполнен**. Дальнейшая работа — потоковые законы с поляризацией
\(D=\kappa E+P_\mathrm{flexo}\), сопряжённые торцевые условия и сильная
механическая МКР с независимым составлением.
