CYL_SOLVER — OPTIONAL VIDEO / GUI / POSTPROCESS QUALITY UPDATE
Date: 2026-08-26

Scope
-----
This update does not change the solver mechanics, MVI/FDM algorithms, constitutive laws,
or accepted-step calculation data. VIDEO is an optional output-only feature.

VIDEO
-----
- Separate VIDEO button. Nothing is generated automatically.
- Reads only already accepted STEP states and writes only RUN/VIDEO/*.mp4.
- Modes for non-Birger runs:
  * 3D deformation
  * 3D stress
  * 3D strain
  * selected 3D field
  * 3D cutaway through thickness
  * 3D + load-deflection
  * x-z section
  * s-z section
  * through-thickness profile
  * ALL main videos
- Birger GB/G0 video is shown only for a saved Birger run.
- No J2/plasticity VIDEO item is exposed in this build.
- User options: every Nth accepted step, FPS, seconds per accepted step, resolution.
- Global color scale is fixed across a video to avoid misleading frame-to-frame recoloring.
- Intermediate accepted steps are reconstructed in memory; FULL is not launched.
- MP4 is encoded to a temporary file, validated, then atomically published.
- Cancel/error cleanup removes incomplete MP4 files.

GUI / RESULTS
-------------
- Accepted-step counter and percentage are drawn inside the green progress bar.
- THROUGH_THICKNESS is physically populated and visible in the results browser.
- 3D shell and 3D through-thickness cutaway are separate visible controls.
- Intermediate accepted steps can show fields/profiles/3D without a prebuilt DERIVED package.

POSTPROCESS
-----------
- Full reconstruction remains limited to the last accepted step.
- Existing Excel, XZ/SZ sections, THROUGH_THICKNESS, DERIVED and standard output remain intact.
- Repeated reconstruction/plot work in FULL was reduced; no output category was removed.
