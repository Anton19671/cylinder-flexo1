V14 — Carrera CUF von Karman + Hooke/Birger и явное меню
Дата: 2026-08-22

ЧТО ДОБАВЛЕНО

1. Отдельная CUF-ветвь умеренных поворотов von Karman для TE1--TE4.
   Она сохраняет цилиндрическую метрику H=1+z/R и член w/R.
   Это не переименование полной Green--Lagrange ветви.

2. Для CUF-von-Karman доступны два материальных режима:
   - обычный линейный закон Гука;
   - метод переменных параметров упругости Биргера.

3. Интерфейс независимо показывает:
   - теорию: Carrera CUF или Kirchhoff--Love;
   - модель CUF: TE1, TE2, TE3, TE4;
   - геометрическую модель;
   - закон материала;
   - численный метод: МВИ или МКР/FDM.

ПОЛНЫЙ СПИСОК ДОПУСТИМЫХ СОЧЕТАНИЙ

Carrera CUF TE1--TE4:
  Линейная + Закон Гука
  Линейная + Биргер
  von Karman + Закон Гука
  von Karman + Биргер
  Green--Lagrange + Гук S--E (StVK), экспериментальный
  Green--Lagrange + Биргер S--E, экспериментальный

Kirchhoff--Love:
  Линейная + Закон Гука
  Линейная + Биргер
  von Karman + Закон Гука
  von Karman + Биргер
