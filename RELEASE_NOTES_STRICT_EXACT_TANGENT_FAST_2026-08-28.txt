CYL_SOLVER — STRICT MVI exact frozen-GB tangent acceleration
Date: 2026-08-28

Scope
-----
Only the CUF MVI tangent path was changed. Birger outer equations, material law,
load stepping, boundary conditions, STRICT half-step order, convergence criteria,
and accepted physical residual equations were not changed.

What changed
------------
1. STRICT MVI now prefers the already available exact directional tangent at
   frozen K0/GB for:
   - LINEAR CUF,
   - von Karman CUF,
   - Green-Lagrange CUF.
   Unsupported/legacy residuals retain the verified central finite-difference
   tangent fallback.

2. Exact MVI profile columns are safely grouped by conservative two-layer
   derivative supports:
   - X-profile directions are colored by disjoint axial x supports;
   - Y-profile directions are colored by disjoint circumferential s supports.
   Because the tangent action is linear at the fixed base state/frozen GB,
   K_T(T1+T2)=K_T T1+K_T T2; columns are extracted only where their conservative
   residual-row supports do not overlap.

3. GUI progress events continue to report tangent-column progress and now also
   carry tangent_action/tangent_actions diagnostics for the exact colored path.

Verification performed
----------------------
- Exact colored vs exact uncolored tangent: max absolute difference = 0 in the
  tested LINEAR, von Karman and Green-Lagrange TE1 cases.
- Green-Lagrange profile coloring checked for TE1..TE4, rank 1 and 2, with CCCC,
  clamped-free, free-clamped and elastic end conditions: max difference = 0.
- Full STRICT LINEAR solve 21x21: identical reconstructed field, identical
  cycles and final projected residual; benchmark about 1.8x faster.
- Full STRICT LINEAR solve 41x41: identical reconstructed field, identical
  cycles and final projected residual; benchmark about 2.0x faster.
- 81x81 TE1 rank=1 profile tangent diagnostics:
    X: 474 active columns -> 64 exact actions (~7.4x fewer actions)
    Y: 486 active columns -> 54 exact actions (9.0x fewer actions)
  Exact wall-time gain depends on mechanics cost and the rest of the reduced
  MVI algebra, so action-count reduction is not identical to total speedup.
- Exact tangent vs retained central-FD reference on a representative small case:
    LINEAR/VK relative inf difference ~1e-11;
    Green-Lagrange ~3e-8 to 4e-8 (finite-difference truncation level).
- Existing checks passed:
    MVI_HALFSTEP_RESIDUAL_ALIGNMENT_SELF_CHECK_V11
    PLATE_STYLE_MVI_SELF_CHECK_V13
    CUF_VK_MODE_SELF_CHECK_V14
    MVI_1_8_COMMON_LOAD_SELF_CHECK
    FINAL_RELEASE_REGRESSION (full PASS after temporarily excluding the
    pre-existing BC_AUDIT_SELF_CHECK_2026_08_27.py Z2 unused-import issue).
