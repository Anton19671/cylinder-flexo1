Main changes:
1. Added selectable CUF internal MVI algorithm:
   - STRICT_HALFSTEP
   - PLATE_STYLE_ONE_CORRECTION (legacy retained)
2. Standard CASE/launcher path selects STRICT_HALFSTEP while low-level API remains backward-compatible.
3. STRICT_HALFSTEP uses one fixed reference scale for the raw reduced residual T^T W R across the Y->X solve.
4. Added guarded automatic load-step subdivision in the common CUF load-series driver.
   On a numerical failure, the solver inserts the midpoint between the last accepted and requested load factor, then retries the original target after an accepted midpoint.
5. Added metadata for accepted states:
   requested_step_index, subdivision_depth, is_substep.
6. Subdivision settings are propagated from FINAL_CASE through the dispatcher.
