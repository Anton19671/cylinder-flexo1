IMPORTANT KL DIAGNOSTIC NOTE
----------------------------
Stage9F intentionally reuses the same Stage8C1 KL Birger material-point
adapter as the already existing KL MVI Green-Lagrange+Birger route. That KL
adapter reconstructs plane-stress intensity measures from the shell strains
and retains detF=1 as a compatibility diagnostic because the displacement-only
KL shell layer does not reconstruct the full 3D through-thickness deformation
gradient used by CUF. Therefore delta_J_limit is not a full 3D deformation-map
guard in KL; this behavior was NOT newly introduced by Stage9F.
